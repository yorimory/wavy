Структура экспорта Stitch (WAVY CRM)
====================================

design-system/DESIGN.md     — токены, типографика, принципы UI
brand/logo/index.html      — логотип / айдентика

screens/                    — экраны по смыслу, внутри — платформа (mobile | desktop), варианты — v1, v2

  onboarding/     mobile | desktop
  dashboard/      mobile | desktop
  calendar/       mobile | desktop
  client_card/    mobile/v1 | mobile/v2 | desktop
  client_list/    mobile | desktop
  smart_retention/ mobile | desktop
  pricing/        mobile/v1 | mobile/v2 | desktop/v1 | desktop/v2
  profile/
    settings/mobile/v1 | v2   — настройки (моб.)
    main/desktop/v1 | v2     — профиль (десктоп)

В каждой конечной папке файл index.html (раньше был code.html).

Открыть обзор всех ссылок: index.html в корне этой папки.
