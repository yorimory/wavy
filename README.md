## 📝 Описание проекта

**Wavy CRM** — это полноценная Fullstack-экосистема (Web + Mobile App), разработанная специально для автоматизации работы частных специалистов и мастеров сферы услуг (мастера бьюти-индустрии, массажисты, репетиторы, тренеры и др.).

Проект полностью адаптирован под мобильные устройства и включает нативный мобильный клиент (на базе React Native/Expo), работающий в связке с асинхронным бэкендом (FastAPI) и веб-приложением (React).

---

## 💎 Ключевые возможности и функционал

### 📅 1. Интерактивный календарь (Панель мастера)
*   **Сетка расписания:** Интерактивное управление временем (просмотр дня/недели).
*   **Адаптивное разделение колонок:** При наложении двух и более записей на один час календарь динамически распределяет ширину колонок без наездов элементов друг на друга.
*   **Бесшовный дизайн сессий:** Смежные часы многочасовых услуг объединяются в единые визуальные блоки без внутренних зазоров и скруглений углов на стыках.

### 🔍 2. Поиск и онлайн-запись (Панель клиента)
*   **Удобный поиск:** Фильтрация мастеров по категориям услуг и имени со стабильным рендерингом иконок категорий Material Symbols.
*   **Интерактивный выбор свободных дат:** Клиенты видят только реально доступное для записи рабочее время мастера с учётом существующих бронирований.

### 💬 3. Полноценная чат-платформа (Чат до бронирования)
*   **Прямое общение:** Клиент может начать переписку с мастером до оформления записи (например, чтобы обсудить детали услуги).
*   **Оптимизированный мобильный интерфейс:**
    *   Поле ввода сообщения и кнопка отправки жестко зафиксированы в самом низу мобильного экрана над панелью навигации и не зависят от количества сообщений.
    *   Блокировка прокрутки основного экрана (body scroll lock) при открытом окне чата.
    *   Выделенная контрастная область сообщений в мягком пастельном лавандовом оттенке (`bg-surface-container-low`) для удобства чтения.

### 🔔 4. Система PUSH-уведомлений
*   **Нативные оповещения на телефонах:** Поддержка службы Expo Push Notifications.
*   **Интеллектуальные сценарии событий:**
    *   Клиент получает уведомление, если мастер подтвердил, отменил или перенёс запись на другое время.
    *   Мастер мгновенно оповещается при отмене сеанса клиентом.
*   **Динамическая маршрутизация:** Нажатие на push-уведомление автоматически перенаправляет пользователя внутри приложения на нужный экран (например, в `/messages` при входящем сообщении или в `/calendar` / `/my-bookings` при изменении статуса записи).

### 📈 5. Модуль удержания клиентов (Retention)
*   **Анализ клиентской активности:** Автоматическое вычисление «оттока» и выявление клиентов, которые давно не записывались.
*   **Автоматические приглашения:** Мастер может отправлять напоминания или персональные предложения клиентам прямо из панели удержания.

### 👤 6. Профили пользователей и Отзывы
*   **Аватарки:** Возможность загрузки квадратных изображений аватарок с компьютера или телефона как для клиентов, так и для мастеров (без использования сторонних внешних ссылок).
*   **Отзывы и рейтинги:** Клиент автоматически видит модальное окно с предложением оставить оценку и отзыв сразу после успешного завершения записи. Оценки мастеров формируют их публичный рейтинг.

## 🛠 Технологический стек

### Frontend Web
*   **React 18** (TypeScript) + **Vite** для быстрой сборки.
*   **Tailwind CSS** (дизайн в концепции Material Design 3).
*   **Адаптивный макет (Responsive Layout)** для любых разрешений экрана.

### Backend
*   **FastAPI** (Python 3.10+) — высокопроизводительный асинхронный веб-фреймворк.
*   **SQLAlchemy ORM** + асинхронный драйвер MySQL (`aiomysql` / `pymysql`).
*   **Pydantic v2** — строгая валидация и типизация данных.

### Mobile App
*   **React Native** + **Expo SDK** — гибридный WebView-клиент с нативной интеграцией push-уведомлений, контролем жизненного цикла устройства и динамической маршрутизацией.

### База данных и контейнеризация
*   **MySQL 8.0** — реляционное хранилище.
*   **Docker / Docker Compose** — оркестрация и быстрый локальный запуск.

## 🚀 Локальный запуск проекта

### Шаг 1: Запуск через Docker Compose (Рекомендуемый способ)
Этот способ автоматически запустит базу данных MySQL, API-сервер бэкенда и React-клиент:

1. Убедитесь, что у вас установлен Docker и запущен Docker Desktop.
2. В корневой директории проекта выполните команду:
   ```bash
   docker-compose up --build
   ```
3. После успешного старта:
   * **React Веб-интерфейс** будет доступен по адресу: [http://localhost:3080](http://localhost:3080)
   * **API бэкенда** доступно по адресу: [http://localhost:8000](http://localhost:8000)
   * **Документация API (Swagger)** доступна по адресу: [http://localhost:8000/docs](http://localhost:8000/docs)

*Примечание: База данных автоматически инициализируется скриптом `server/sql/init.sql` с тестовыми данными и сложным паролем администратора.*

---

### Шаг 2: Запуск мобильного приложения (Expo)

Для отладки мобильного приложения на телефоне или в симуляторе:

1. Перейдите в папку `mobile`:
   ```bash
   cd mobile
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите Expo CLI:
   ```bash
   npx expo start
   ```
4. Скачайте приложение **Expo Go** на свой телефон (iOS/Android) и отсканируйте QR-код из терминала для запуска мобильной версии приложения Wavy CRM.

## ☁️ Облачная архитектура (Production)

Система полностью готова к деплою в облако:
*   **Фронтенд:** Разворачивается на хостинге **Vercel** или Netlify.
*   **Бэкенд:** Запускается через Docker-контейнер на **Render** / Railway.
*   **База данных:** Подключение к распределенной MySQL-совместимой БД **TiDB Cloud Serverless**.
