## 📝 Описание проекта

**Wavy CRM** — это полноценная Fullstack CRM-система, разработанная специально для автоматизации работы частных специалистов и мастеров сферы услуг (парикмахеры, мастера маникюра, массажисты, репетиторы и др.). 

Система решает ключевые боли частного бизнеса: автоматизирует ведение записей в интерактивном календаре, упорядочивает клиентскую базу и предлагает уникальный интеллектуальный модуль удержания клиентов для предотвращения оттока аудитории.

---

## 💎 Ключевые возможности и функционал

### 📅 Интерактивный календарь (Панель мастера)
*   **Гибкое управление временем:** Специальная интерактивная сетка расписания (день/неделя).
*   **Индивидуальный график:** Автоматическое скрытие нерабочих часов на основе настроенного графика мастера.
*   **Интеллектуальные блокировки:** Многочасовые услуги автоматически блокируют все занятые временные слоты. Сетка динамически расширяется при наличии записей вне стандартного времени.

### 🧠 Модуль Smart Retention (Умное удержание)
*   **Анализ оттока:** Алгоритм автоматически рассчитывает вероятность оттока клиентов на основе частоты их визитов.
*   **Персональные рекомендации:** Система генерирует готовые подсказки для мастера (например, отправить напоминание или предложить персональную скидку).

### 🔍 Поиск и онлайн-запись (Панель клиента)
*   **Удобная витрина:** Раздельный поиск специалистов по категориям услуг и имени.
*   **Умные слоты:** Интерактивный выбор свободных дат и времени. Клиент видит только реально доступные для записи интервалы мастера.

### 🛡️ Автоматическая модерация контента
*   **Контроль безопасности:** Встроенный модуль проверки текстов и отзывов на спам и нецензурную лексику с гибкой настройкой строгости фильтрации (Low/Medium/High).

## 🛠 Технологический стек

### Frontend
*   **React 18** (TypeScript) — компонентная архитектура интерфейса.
*   **Vite** — быстрая сборка проекта.
*   **Tailwind CSS** — современный дизайн, основанный на дизайн-системе Material Design 3.
*   **Responsive Layout** — полная адаптация интерфейса для мобильных устройств, планшетов и ПК.

### Backend
*   **FastAPI** — высокопроизводительный асинхронный веб-фреймворк на Python.
*   **SQLAlchemy ORM** — объектно-реляционное сопоставление для работы с БД.
*   **Pydantic v2** — валидация входных данных и сериализация ответов.

### База данных и деплой
*   **MySQL 8.0** — основное реляционное хранилище.
*   **Docker / Docker Compose** — контейнеризация всех микросервисов проекта.

## ☁️ Облачная архитектура (Production)

Проект полностью готов к работе в облаке и развернут по следующей схеме:
*   **Frontend-хостинг:** Vercel (быстрая раздача статики через CDN).
*   **Backend-хостинг:** Render (контейнеризированный запуск API).
*   **Облачная база данных:** TiDB Cloud Serverless (распределенная отказоустойчивая база данных MySQL).
